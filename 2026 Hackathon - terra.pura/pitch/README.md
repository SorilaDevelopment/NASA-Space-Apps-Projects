# terra.pura pitch deck

7-slide pitch for terra.pura (NASA Space Apps Challenge 2026). Host it at **https://slides.sorila.dev/terrapura-pitch/**.

- **Plain static site:** upload this folder as it is. There's no build, no server code and no external requests (fonts, images and the QR code are all local).
- **Relative paths:** serve it with a trailing slash (`/terrapura-pitch/`) so they resolve.
- **Controls:** ← → / space / click to move, F full screen, N speaker notes, 1–7 to jump, swipe on touch screens. Each slide has its own URL (`#1` to `#7`).
- **Screenshots:** the images in `shots/` are real captures of terrapura.sorila.dev. Replace them with new captures of the same name to refresh the deck.
